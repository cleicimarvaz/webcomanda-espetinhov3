# Seeds

Dados iniciais e dados de desenvolvimento do PostgreSQL V3 serão mantidos aqui.

Seeds não devem conter:

- senhas reais;
- tokens;
- chaves privadas;
- credenciais de produção;
- dados pessoais reais sem necessidade.

O bootstrap provisório em arq/seeds-v3/ permanece separado até a definição final da identidade e do ambiente.
