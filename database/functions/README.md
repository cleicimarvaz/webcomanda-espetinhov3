# Funções do banco

As funções PostgreSQL usadas como parte dos serviços transacionais da V3 serão versionadas aqui.

Cada função deverá registrar claramente:

- objetivo;
- parâmetros;
- retorno;
- permissões esperadas;
- regras de integridade;
- comportamento transacional;
- dependências;
- testes.

As funções provisórias em arq/funcoes-v3/ permanecem como rascunho até a consolidação do banco físico.
